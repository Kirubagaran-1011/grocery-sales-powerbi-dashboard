# How to Build the Dashboard in Power BI Desktop

The `.pbix` file cannot be generated by code, so build it from the cleaned files in about 30 to 45 minutes.

## 1. Load data
1. Power BI Desktop > **Get data > Folder** (or Text/CSV) and choose `data/clean/`.
2. Load `dim_date`, `dim_product`, `dim_customer`, `fact_sales`, `fact_inventory`.
3. In Power Query, check the types: dates as **Date**, `revenue/cost/profit` as **Fixed decimal number**, IDs as **Whole number**.

> Optional: open `data/raw/sales_raw.csv` in Power Query and repeat the cleaning steps there (Remove Duplicates, filter quantity greater than 0, Replace Values, Trim, Capitalize Each Word) so the dashboard shows the complete cleaning process.

## 2. Model
Create the relationships and mark the date table (see `dax_measures.md`). Add all measures.

## 3. Pages

### Page 1: Sales Overview
- **KPI cards:** Revenue, Gross Profit, Profit Margin %, Orders, Avg Order Value
- **Line chart:** Revenue and Revenue LY by `dim_date[year_month]`
- **Column chart:** Revenue by `day_name` (sort by day number)
- **Donut:** Revenue by `payment_mode`
- **Slicers:** Year, Quarter, Category

### Page 2: Product and Category
- **Bar chart:** Revenue by category, with `Revenue % of Total` as a tooltip
- **Table:** product, units, revenue, margin % (with conditional-colour margin)
- **Scatter:** X = Units Sold, Y = Profit Margin %, Details = product_name
- **Card:** Top Product by Profit

### Page 3: Inventory and Stock Trends
- **Cards:** Stock on Hand, Products Below Reorder Level, Stock-out Products
- **Line chart:** Stock on Hand by month
- **Table:** products where Products Below Reorder Level is 1 (filter pane: `below_reorder` = 1)
- **Bar chart:** Stock-out Months by product (top 10)

### Page 4: Customers
- **Cards:** Identified Customers, Repeat Customer Rate %, Walk-in Revenue Share
- **Bar chart:** Avg Order Value by membership
- **Map or bar:** Revenue by area

## 4. Finish
- Use a consistent theme (View > Themes), 2 or 3 colours only.
- Add page navigation buttons, titles and a short "Key insights" text box on each page.
- Save as `Grocery_Sales_Dashboard.pbix` in this `powerbi/` folder and add 3 or 4 screenshots to `powerbi/screenshots/`.
- Note that GitHub cannot preview `.pbix`. Link screenshots in the README, or publish to the Power BI Service and add the link.

## 5. Questions the dashboard should answer
1. Which categories and products drive revenue and profit?
2. Do weekends or festival months (Oct, Nov, Jan) sell more?
3. Are we growing year over year?
4. Which products are running out of stock, and how often?
5. What share of sales comes from repeat or loyalty customers?
